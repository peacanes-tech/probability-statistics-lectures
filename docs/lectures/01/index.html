전설 속 아서왕은 기사들 사이에 높고 낮은 자리가 생기지 않도록 둥근 탁자를 만들었다고 합니다.

회장과 부회장이 이웃하게 앉는 경우

회장·부회장을 포함한 5명이 원탁에 둘러앉을 때

⑴ 5명이 앉는 경우: (5−1)! = 4! = 24
⑵ 비유: 끈으로 묶기
꼭 붙어 앉을 두 사람은 한 사람으로 본다 → 4명의 원순열

(4−1)! = 3! = 6

묶음 안에서 두 사람이 자리를 바꾸는 경우 2! = 2

6 × 2 = 12

서로 다른 n개에서 중복을 허용하여 r개를 택하는 중복순열의 수

nΠr = n × n × ⋯ × n = nr
Π(파이)는 곱(Product)의 P에 해당하는 그리스 문자
순열은 n ≥ r이어야 하지만 중복순열은 n < r도 가능
예: 3Π4 = 34 = 81

같은 것이 있는 순열의 수

n개 중에서 서로 같은 것이 각각 p개, q개, …, r개씩 있을 때, 일렬로 나열하는 순열의 수는

n!p! × q! × ⋯ × r! (단, p + q + ⋯ + r = n)
1, 1, 2, 2, 3으로 만드는 다섯 자리 자연수
5!2!×2!×1! = 30
BANANA (a 3개, n 2개, b 1개)
⑴ 6!3!×2! = 60
⑵ n이 양 끝에: n□□□□n
가운데 b, a, a, a → 4!3! = 4
