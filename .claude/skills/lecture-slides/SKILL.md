# 확률과 통계 강의 슬라이드 만들기

대상: $ARGUMENTS

프로젝트 루트는 `C:\Users\Yoo's family-sub\Desktop\slides`. 먼저 `README.md`의 **회차 목록**에서 이 강의의 폴더와 교과서 범위를 확인한다.
견본은 이 스킬의 `assets/reference-deck.html`(1강, 사용자가 승인한 형식)이다. **엔진·CSS·컴포넌트를 그대로 재사용**하고 내용만 바꾼다.

스크립트 경로: `${CLAUDE_SKILL_DIR}/scripts/`. Python은 항상 `python -I`로 실행한다. 중간 산출물(텍스트 추출, 스크린샷)은 스크래치패드에 둔다.

## 1. 교과서 읽기
1. `00_공통/교과서/`에서 해당 PDF를 찾는다. Read 도구로 PDF가 안 열리면(poppler 없음) 텍스트를 뽑는다:
   `python -I scripts/textbook_dump.py "<pdf>" "<scratchpad>/tNN.txt"` (pymupdf 없으면 `python -m pip install pymupdf`)
2. 해당 범위를 **전부** 읽고 정리한다: 생각 열기, 다가서기, 정의·공식, 예제(쪽수), 문제, 생각 넓히기, 탐구, 수학 이야기, 중단원 마무리.
3. 교과서에 없는 단원이면 만들지 말고 사용자에게 PDF를 요청한다.

## 2. 비유 정하기
- 개념마다 **일상 비유 1개 이상**을 정한다 (1강 예: 원순열=아서왕 원탁·회전목마, 중복순열=자물쇠 다이얼, 같은 것이 있는 순열=모스 부호·이름표 떼기).
- 교과서의 생각 열기·다가서기 상황(혈액형, 식당 주문 등)을 우선 활용하고, 더 생생한 비유를 덧붙인다.
- 대학 1학년 수준의 한 걸음 더(예: 함수 개수 |Y|^|X|, 일반화)를 한두 장 넣는다.

## 3. 비유 그림 찾기 (위키미디어 공용만)
1. 검색: `python -I scripts/commons_search.py "query1" "query2" > <scratchpad>/search.txt` 후 결과 파일을 읽는다. 영어 검색어가 잘 걸린다.
2. 라이선스가 **Public domain / CC0 / CC BY / CC BY-SA**인 것만 고른다. (NC·ND·불명 제외)
3. 받기: `python -I scripts/commons_get.py "<강의폴더>/이미지" name=File:Title.jpg ...`
   - 960px 썸네일과 `출처.json`(작가·라이선스·원본 주소)이 저장된다. 이미 받은 것은 건너뛴다.
   - HTTP 429(요청 과다)가 나면 잠시 뒤 같은 명령을 다시 실행한다.
4. 받은 이미지를 Read로 **직접 보고** 비유에 맞는지 확인한다. 맞지 않으면 다른 것을 고른다.
5. 교과서 그림은 저작권 때문에 **복사하지 않는다**. 필요한 도식은 SVG로 직접 그린다.

## 4. 슬라이드 작성
파일: `<강의폴더>/슬라이드/<강의폴더명>.html`. 이미지는 `../이미지/<name>.jpg`로 참조한다. 외부 라이브러리 없이 파일 하나로 오프라인에서 열려야 한다.

**reference-deck.html에서 그대로 가져올 것**
- `<style>` 전체 (색 토큰, `.box`, `.card`, `.formula`, `.frac`, `.sb`/`.su` 첨자, `.f` 단계 등장, 인쇄 CSS)
- 엔진 스크립트: `go/next/prev/render`, `hooks[slideId](step, animate)`, `#n.step` 해시, F 전체 화면, `tween()`, `el()` SVG 도우미
- 바닥글: `확률과 통계 · N강 제목 · <span id="pageNo">`

**구성 (20~24장 내외)**
1. 표지 (대표 비유 사진 + 강 번호·제목·교과서 범위와 쪽수 + 조작법 한 줄)
2. 오늘의 질문 3개 (사진 카드) + 학습목표 (교과서 문구)
3. 복습·준비하기
4. 개념마다: **비유 사진 슬라이드 → 애니메이션/인터랙티브 슬라이드 → 공식 정리 → 교과서 예제(쪽수 표기)**
5. 함께 풀기 (교과서 문제, 풀이가 단계별로 등장)
6. 수학 이야기나 탐구 → 가능하면 **시뮬레이션**(버튼으로 여러 번 반복해 실험값과 이론값 막대 비교)
7. 오늘의 정리 표 (종류 | 비유 | 핵심 아이디어 | 공식)
8. 연습 문제 (중단원 마무리에서 고르기, 답은 한 단계 뒤에 공개). **답은 직접 계산해 검산한다.**
9. 다음 시간 예고 + 이미지 출처 목록 (CC BY / BY-SA는 작가·라이선스 필수)

**애니메이션 원칙**
- 한 번에 하나씩: `data-steps="N"` + 요소에 `class="f" data-step="k"`.
- 움직임이 개념을 설명해야 한다 (회전 → 같은 배열, 묶기 → 한 덩어리, 이름표 떼기 → 겹침).
- 훅은 `step` 값만 보고 상태를 정해야 한다 (앞뒤로 넘겨도 깨지지 않게). `animate`가 참일 때만 tween.
- 슬라이드 안 버튼은 키보드 진행과 별개로 동작한다 (다시 뽑기, 자동 N번, 초기화).

**글쓰기**: 한국어, 짧은 문장, 핵심어는 `<b>` 또는 `<b class="hl">`. 한 장에 상자 3개 이하.

## 5. 검증 (보고 전에 반드시)
1. 각 슬라이드를 마지막 단계로 찍는다:
   `python -I scripts/shoot.py "<deck.html>" "<scratchpad>/shots" 1.0 2.4 3.3 ...`
2. 스크린샷을 모두 Read로 보고 고친다: 아래로 넘침(바닥글 겹침), 수식 줄바꿈, 이미지 잘림, 빈 그래프.
3. 고친 장은 다시 찍어 확인한다.
4. 버튼 동작은 헤드리스로 확인할 수 없으므로, 확인하지 못했다고 보고한다.

## 6. 마무리
- `README.md` 회차 목록의 상태를 갱신한다.
- 완성한 슬라이드를 브라우저로 연다: PowerShell `Start-Process "<deck.html>"`.
- 사용자에게 보고: 장 수, 개념별 비유와 애니메이션 표, 이미지 출처 요약, 확인한 것과 못 한 것.
